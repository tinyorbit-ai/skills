# Brief contract

Read this file in full during forge-discovery step 4.

Replace the `wiki/brief.md` stub with these sections in order:

- **What it is** — the user's paragraph.
- **Who & when** — the specific moment plus who/when.
- **How it should feel** — the experiential target.
- **The hard/interesting part** — the hunch, or "not sure yet".
- **The friction it replaces** — current effort/attention and observed surprises.
- **Smallest useful version** — the seed for phase 1.
- **Human evidence** — observed real use; or `Unknown — schedule a human-evidence
  gate after the smallest useful workflow and before billing/scale/polish`, naming
  who should try which task.
- **Three-year fit** — more/less/same and why.
- **Constraints** — stack, platform, fixed shape.
- **Non-goals** — what it explicitly is not.
- **Shape chosen** — the picked shape and one-line reason over alternatives.
- **What you're drawn to / unsure about** — omit only for "don't know yet".

Keep it to a page. Write an ADR for any genuine decision (shape or fixed
constraint) and link it from `wiki/index.md`.

File document seeds and durable discovery context into `wiki/knowledge/` through
forge-wiki (nearest-fit topic; `project-genesis` when new). Cite sources from the
brief with wikilinks rather than compressing them away.
