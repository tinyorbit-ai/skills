# Rubric — grade the implementation on three dimensions, 0–10 each

The attached `forge-principles` simplicity standard defines the economy bar.

**Pass floor: every dimension ≥ 7.**

1. **correctness_and_edges** — `GET /health` preserves its route, status, and response
   shape while returning the approved `orbit-api` service identifier.
2. **economy_of_delegation** — the frontier owner locks the exact change, gives one
   Sonnet/Terra mechanic a closed file list and deterministic check, collects the
   result, reads the diff, and does not create a repair loop or unnecessary abstraction.
3. **brief_fidelity** — source, tests, example, and docs all use `orbit-api`; the old
   identifier is gone; the focused suite and live behavior prove the propagation.
