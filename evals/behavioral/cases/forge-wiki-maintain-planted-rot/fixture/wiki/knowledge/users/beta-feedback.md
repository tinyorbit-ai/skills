# Beta feedback — the receipt is the trust moment

> **Summary:** The dry-run receipt is what made a first-time user willing to run it for real.

## Core Concept

Watching one person try tidyshots: they read the entire dry-run receipt line by
line before agreeing to a real run. The receipt isn't a convenience feature — it's
the trust mechanism that makes the destructive-feeling operation acceptable.

## Key Points

- The per-file date-source column got read; the summary counts did not.
- "Nothing to do" on the second run was described as "the reassuring part".
